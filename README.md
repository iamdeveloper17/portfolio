## ✨ About This Project

A modern, fully-responsive developer portfolio built from scratch — no templates, no shortcuts. Designed to showcase production-ready projects with clean architecture, smooth animations, and a professional dark theme.

**Live Site:** [portfolio-rho-sage-80.vercel.app](https://portfolio-rho-sage-80.vercel.app/)

- ⚡ **Blazing Fast** — Vite + React 19

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/iamdeveloper17/portfolio.git

# Navigate to project
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
Open http://localhost:5173 in your browser.

Build for Production
bash
npm run build
npm run preview
📝 Adding New Projects
Edit src/data/projects.js and add a new object:

js
{
  id: 7,                                    // Unique ID
  title: "Your Project Name",
  description: "What it does and what problem it solves",
  image: "/projects/your-image.png",        // Place in public/projects/
  tags: ["React", "Node.js", "MongoDB"],
  liveLink: "https://your-project.com",
  githubLink: "https://github.com/iamdeveloper17/your-project",
}
The website will automatically render the new project.

🎨 Customization

Projects data	src/data/projects.js

Footer	src/components/Footer.jsx
Colors, animations	src/index.css
